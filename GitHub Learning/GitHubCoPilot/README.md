# Hooks
A GitHub Copilot Hook is a custom command that automatically runs at a specific point in the CoPilot agent's workflow

### GitHub CoPilot Hooks Common Use cases
- **Run checks:** Start linters, formatters, or tests at a chosen point in the agent workflow.
- **Validate changes:** Check generated code, configuration, or documentation against project conventions.
- **Protect sensitive data:** Scan proposed changes for secrets or credentials before they are shared or committed.
- **Automate setup and cleanup:** Prepare a development environment before a task, or remove temporary files afterward.
- **Enforce safeguards:** Require approvals or block a workflow when a required check fails.
- **Improve visibility:** Log workflow events or notify a team when important stages are reached.
