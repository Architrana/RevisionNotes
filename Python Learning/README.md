## Setting Up and Basic commands

```bash
python3 -- version # show version of installed python
python3.12 --version # shows if any version of 3.12 is available on machine

# creates a venv using 3.12 without changing your system Python or other projects.
cd backend
python3.12 -m venv .venv

# Activate it in that terminal:
source .venv/bin/activate
```
